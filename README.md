# ReactOS

ReactOS is a small fun project: a portfolio website inspired by the classic **Windows 95** look and feel, built with 
**React** and **Vite**.

The idea was to recreate a nostalgic desktop-style interface in the browser and use it as a playful way to present my
portfolio and projects.

This project is not meant to be a full desktop simulation, but rather a retro-inspired portfolio experiment.

## Features

- 🖥️ Windows 95–inspired user interface
- 📂 Desktop-like navigation for portfolio content
- ⚡ Fast development environment powered by Vite
- ⚛️ Component-based structure using React
- 🎨 Retro / nostalgic UI design

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Installation

Clone the repository:

```bash
git clone <repo-url>
cd reactos
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at http://localhost:5173

## Build

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
